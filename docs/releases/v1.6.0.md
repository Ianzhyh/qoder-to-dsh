## 1.6.0

**可靠性大版本。** 重点不是加功能，而是让「一次任务」在上游看来仍然是一次任务，并让工具失败、未知内容块、图片超限、额度/排队错误不再静默丢语义。

- **任务身份**：按「会话 + 最后一条 user」归并一次工具循环，稳定 `request_set_id` / `session_id` / `business.id` / `begin_at`；首次 `start`，成功后 `processing`；只有 `request_id` / `chat_record_id` 每次新。一次 N 步任务不再被上游记成 N 条对话，直接缓解 `Billing daily count exceeded`（code 110）。
- **释放租约**：一轮结束 best-effort 调 `/api/v2/service/ask/finish`，失败只写日志；`QODER_ASK_FINISH=0` 可关闭。
- **内容保真**：工具 `isError` 用 `[tool error]` 透传；`mcp_tool_use` / `web_search_tool_result` / 工具图片降级成带标签文本；正文里的 DSML / `<function=` / 工具调用回声以 `TOOL_CALL_LEAK` 结束，避免假完成。
- **请求体预算**：最近 50 张图 / 40 MiB 预检，超限从最旧图片降级；仍超限给可读错误。`QODER_MAX_IMAGES` / `QODER_MAX_BODY_BYTES` 可调。
- **模型预检**：目录热时拒绝目录外模型，目录冷/过期时透传；`QODER_SKIP_MODEL_PREFLIGHT=1` 逃生门；`[1m]` / `-1m` 后缀会先剥掉。
- **错误动作矩阵**：`pricingUrl`、`usage limit reached`、503 `queued the request` 归入额度/排队；每个错误码给 `wait / switch / retry / compact / relogin / pick-model / fail`，账本与面板共用。请求页新增「仅需处理」。
- **额度**：企业版 `orgResourcePackage` 可读；限时免费带截止时间；上游缺 usage 时估算并标 `estimated`。
- **跨平台**：macOS/Linux 安装根、数据目录、CLI `~/.qoder[.cn]/.bin/runtime-info*`、`Cosy-MachineOS` 支持；桌面端 `auth.v1.dat` 导入仍只支持 Windows，其他平台明确引导到 CLI / PAT。
- **诊断**：新增「宿主能力」检查；`na` 状态不再显示成红色失败；签到显示设备身份来源，并提示国际版同设备通常仅首个账号可领。
- **面板（11-03 收口）**：请求明细不再撑破设置面板（表格按内容排布、窄面板只内部滚动），模型筛选补上原生 `<select>` 的深色样式；额度到期三态（有日期 / 明确永久 / 上游未返回），不再把缺失说成「不限期」；资源包改可展开折叠行；新增「每日赠送 · 按到期分批」——用本地领取账本还原逐笔到期（领取时刻 + `benefit.validity`，没给按每日赠送 30 天推算并标注），先到期先扣，账本没记到的单列「到期未知」；再登录覆盖登录态后账号列表不再少一行（`known` 快照补回「需重新登录」占位）；热力图选中行补样式。
- **测试**：适配器测试不再写真实用量账本（此前 `npm test` 会把假失败记录带进请求页）。

### 升级

tgz（推荐，可核对 SHA-256）：

```bash
dsh plugin --profile desktop add ./qoder-to-dsh-1.6.0.tgz
```

GitHub 直装：

```bash
dsh plugin --profile desktop add github:Ianzhyh/qoder-to-dsh
```
