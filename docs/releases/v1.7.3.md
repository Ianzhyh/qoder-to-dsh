## 1.7.3

**后端语义版本。** 只修正确性，不加功能。三件事：一条脏数据不该让插件起不来，错误码不该把用户指错方向，额度与账目必须能自证。

### 修复

- **插件加载失败**：领取账本用 `new Date(at).toISOString()` 做去重键。上游把秒/纳秒写进 `at`（`1e17`、`1.7e18`）时抛 `RangeError: Invalid time value`，而这行在 `apply()` 里同步执行 —— 整个面板与模型全部不可用。越界记录现在直接丢弃。
- **错误码指错方向**：403 + `{"code":110}`（日限）、`{"code":112}`（额度不足）、`{"code":114}`（试用受限）以前全部判成 `AUTH`，提示「登录态已失效，请重新授权」。实际该等明天、换号或换免费模型。根因是分类器只收到裸数字 `110`，而判定函数要的是 `code 110` 这种形状。
- **硬额度被当作排队**：额度不足的响应也常带 `retryAfterSeconds`，先命中排队规则就给出「等待」而不是「换号」。现在硬额度排在排队之前；真正的 10605 排队仍然给等待。
- **额度不可自证**：已过期的资源包仍计入剩余，面板显示「剩余 150 / 400」而真实可用只有 50。过期包不再进合计，但仍展示并标注已过期。
- **账目污染不可逆**：`usage.billable !== false` 把「上游没给这个字段」钉成 `true`。一旦落盘，免费模型的消耗就被永久记成实扣，且 `reconcileUsage` 因为 `billable !== undefined` 直接跳过 —— 越晚修，历史账越脏。现在保留三态。
- **同页两套口径**：`totals` 在明细被裁剪时改用每日汇总，`byModel` 只遍历明细，但占比仍用 `totals` 当分母。同一页面出现「今日 7 次」与「按模型合计 2 次」、占比合计 0.2857。
- **失败拆分丢失**：按动作/按码的拆分算好后没有返回，面板的「今日请求」永远只显示「N 次失败」。
- **目录升级后不放行新模型**：`catalogClientStale` 只由客户端侧赋值，adapter 读的是自己从不写的字段。CLI 升级后新上线模型被本地校验拒成「不在当前目录」。
- **签到账本两处失真**：去重按 UTC 记日（北京 00:00–08:00 的两次领取被并成一天）；超过 500 条时丢掉最早的领取，早期批次整体消失。
- **令牌过期变成 500**：`QoderAuthError` 没有 `statusCode`，路由按 500 返回；前端把 `>=500` 当网络抖动继续轮询，用户永远停在「正在重试授权状态」。现在映射成 401。
- **三个 GET 缺副作用门**：`/qoder/accounts`、`/qoder/pats`、`/qoder/checkin` 会落盘账号或解密凭据库，但只检查了方法。不带面板头的跨站 GET 就能触发。
- **其他**：用户主动取消被列进「仅需处理」；余额未知渲染成 `0 / 1000`；未分类错误码 `PROVIDER_ERROR` 不在枚举里导致提示为空；价格未知显示「×0 Credits」；签到失败账号一天重试 42 次；`.bak-*` 备份无限堆积；POSIX 下漏认无后缀的 `runtime-info`；`999949` 显示成「1000K」；英文界面的模板串只换标点、正文仍是中文。

### 复核说明

审计报告共 25 条。逐条在本机复现后，**22 条为真并已修复**，3 条不成立：`addonBatches` 的扣减方向（函数文档明确写「剩余余额留在越新的批次里」，当前实现正是该语义，报告把方向判反了）、`recentLogs` 行数不足（1.7.1 的按需读已修复，实测 60/200 行都正常）、`next` 标记（确为脏字段，已加条件；但报告说的「全库无消费方」属实，所以只是收窄而非功能修复）。

### 已知边界

- 免费模型的旧账（1.7.3 之前写入的 `billable:true`）无法自动回补；`reconcileUsage` 只在 `billable` 缺失时才修正。需要重建历史账的话，只能清空本地用量重新统计。
- 签到重试改为只对 `pending`/`waiting` 当天重试；`error` 类失败要等次日 10:00 或手动点「重试签到」。

### 升级

tgz（推荐，可核对 SHA-256）：

```bash
dsh plugin --profile desktop add ./qoder-to-dsh-1.7.3.tgz
```

GitHub 直装：

```bash
dsh plugin --profile desktop add github:Ianzhyh/qoder-to-dsh
```

装完**完全退出 dsh 再打开**。如果面板顶部提示“已加载 vX，磁盘 vY”，说明还在跑旧代码。

- 凭据、偏好、用量、签到与目录缓存都在 `<DSH_HOME>/qoder`，升级不会清空。
- 已经登录的账号不需要重新授权。
