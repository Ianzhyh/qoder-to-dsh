## 1.3.1

**这一版修「挂起、假成功、被绕过的读接口」。** 网关 5xx 切换后不再卡死；用户取消/换号不再被记成可重试的传输错误；PAT 验证失败与凭据落盘失败会如实报错；`/qoder/account` 与 `/qoder/models` 重新要求面板头。设置面板同时完成一轮动效、材质与 rem 字阶打磨。

- **网关卡死**：5xx 响应被 drain 后仍被当成可读响应，后续网关传输失败时会在已结束的响应上永久等待；现在清空旧响应并抛出最后的错误。
- **取消与换号**：客户端干净关流时不再被误判为 `TRANSPORT`；按取消/账号代次记 `ABORTED`，用量状态同步为 `aborted`。
- **断流与工具调用**：干净 EOF + 半截工具参数返回可重试的 `TRANSPORT`，不再误报 `INVALID_REQUEST`。
- **凭据真实性**：PAT 的 userinfo 验证遇到网络/5xx 失败会回滚并报错；凭据异步落盘失败会抛给登录流程，不再假成功。
- **错误分类**：110 日限不再被带 `retryAfter` 的响应伪装成排队限流；`context deadline exceeded` 归为超时，`frequency_penalty` 不再触发限流。
- **目录与签到**：HTTP 200 错误信封不再变成空目录；上游确认已领取但金额为 0 时不再报错重试；`umid` 版本目录改为数字段排序。
- **面板读接口**：`/qoder/account` 与 `/qoder/models` 会触发上游请求或凭据写入，现在要求 `x-qoder-panel: 1`；面板与对话页胶囊自动携带。
- **面板体验**：弹簧曲线、按压反馈、玻璃浮层、可逆退场、rem 字阶、图表指引线 1:1 跟手与键盘同步；切区间失败会明确提示仍在展示旧数据；深刷新期间暂停浅轮询。
- **验证**：206 个用例通过；离线 CDP 验证动效、图表、失败态与对话页胶囊，console errors 0。

### 升级

tgz（推荐，可核对 SHA-256）：

```bash
dsh plugin --profile desktop add ./qoder-to-dsh-1.3.1.tgz
```

```bash
dsh plugin --profile desktop add github:Ianzhyh/qoder-to-dsh
```
