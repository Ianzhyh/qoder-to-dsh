## 1.5.1

**1.5.0 的缺陷收口。** 重点修诊断包脱敏、额度状态、账号/PAT 切换后的残留，以及「已成功却提示失败」的写入错误。

- **诊断包**：`checks.detail` / `hint` 等所有字符串都递归脱敏，邮箱 `a***@domain`、UUID 尾 6 位、令牌样式 `<token>`；不再只脱敏顶层账号字段。
- **额度**：过期不足一天按毫秒判 `expired`；只有 total 没有 remaining 显示 `—` / 「剩余未知」，不再显示 0；无限额度胶囊显示 `∞ / 不限量`，不再出现 `-1 / -1`；只有加量包时不再重复成两行。
- **账号**：当前账号隐藏后显示「恢复」；上移/下移只在可见行之间交换，隐藏行不再让按钮空转；切换账号会清掉旧额度卡；切到桌面账号/退出后 PAT 的「当前」标记不再残留。
- **PAT/账号写入**：`pats.json` / `accounts.json` 写入失败只返回 warning，不回滚已经成功的登录/切换；UI 提示会带原因。
- **请求/用量**：切时间窗口后模型筛选不在新窗口时自动回退「全部模型」；用量 CSV 的已省列补上 `savedCredits`；用量页新增「按账号」聚合卡。
- **旧构建提示**：额度接口 404/405 且没有额度数据时，额度卡与诊断都会提示「宿主可能是旧构建，完全退出 dsh 再打开」。
- **目录刷新**：客户端升级触发的 stale 刷新失败一次后回到正常 TTL，不再每个请求都重试上游。

### 升级

tgz（推荐，可核对 SHA-256）：

```bash
dsh plugin --profile desktop add ./qoder-to-dsh-1.5.1.tgz
```

GitHub 直装：

```bash
dsh plugin --profile desktop add github:Ianzhyh/qoder-to-dsh
```

装完**完全退出 dsh 再打开**。如果面板顶部提示“已加载 vX，磁盘 vY”，说明还在跑旧代码。
