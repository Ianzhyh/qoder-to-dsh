## 1.7.2

**面板前端缺陷收口。** 只修显示与交互，不动上游协议和数据格式。重点是把「英文界面实际渲染出什么」这条一直没人验证的路径补上，以及几个时间/遮挡类的显示错误。

### 修复

- **英文界面半中半英**：翻译器先跑正则、再对短语表做子串替换，键是片段而不是整句。于是后端下发的整句 `本机已没有这个账号的登录态（客户端同区只保留一份），重新登录后恢复。` 被拆成 `本机已没有这 accounts的Sign in态…`；实测 30 条后端整句有 17 条残留中文。现在后端整句和含变量的模板句都整句入字典，残留归零。
- **含变量模板句断裂**：`把 Claude 设为默认模型` 会输出 `把 Claude Set as default model` —— `把` 留在原地。`取消 X 的默认模型`、`把 X 的上下文…恢复为官方默认？` 同理。
- **计数句吞掉单位**：`12 / 14 个模型匹配 · 已显示 9 个` 的真实渲染串带 `/` 前缀，原有正则要求纯数字开头，英文变成 `12 / 14 modelsmatch · Shown 9`。
- **`今天到期` 拼错**：徽标由 `'今天'` + `'到期'` 两段拼出，分别被替换成 `Today` 和 `Expires`，输出 `TodayExpires`。
- **CSV 导出用 UTC**：界面显示 `21:30`，导出的 `time` 列是 `13:30Z`。对账时像是数据错了，跨日统计还会把 00:00–08:00 的请求算到前一天。改为本地时间 `YYYY-MM-DD HH:mm:ss`。
- **跨年时间不显示年份**：`stamp()` 只给 `MM-DD HH:mm`，一年前的 11-09 和今天长得一模一样。非同年记录现在带年份。
- **额度已过期却看不出来**：最近到期那行在已过期时不追加任何后缀，只显示「最近到期 11月9日」；旁边的徽标却说「有额度已过期」。两处口径已统一。
- **整页白屏**：`GET /qoder/credits` 返回 200 但缺 `totals`（空 body 会被兜成 `{ ok:false }`，绕过判空）时，`data.totals.credits` 抛 `TypeError`，而面板没有 error boundary —— 整个「用量」页消失。现在做结构判空并给出可重试空态；`series[mode]` 缺键也回落成空图。
- **切维度后悬停列不复位**：`全部 / 按模型 / 按客户端` 切换时天数没变，悬停索引被保留，指引线停在上一个维度的列上。
- **语言偏好只写不读**：服务端 `prefs.uiLocale` 从来没被读回来，换机器或清了浏览器存储就退回系统语言；同时每次打开面板都无条件写一遍，多窗口会互相覆盖。现在本地没有选择时采纳服务端值，写入只在用户主动切换时发生。
- **签到开关会存反**：开关用「生效值」（被 `QODER_CHECKIN=0` 短路的那个）取反，环境变量禁用时点一下会把配置静默翻成开启。改用用户配置值。
- **别名按 Esc 仍被保存**：输入框失焦先于 Esc 生效，取消动作拦不住已经触发的保存。
- **PAT 列表可能被旧快照盖回**：它是唯一没有请求序号的加载器，慢网络下「刷新 → 立刻切换」会让刚切换的「当前」标记消失。
- **首屏重复请求**：`/qoder/models` 与 `/qoder/prefs` 各多打一次。
- **试跑取消判定**：改为看自己持有的取消信号，而不是错误类型名；宿主断开时不再显示英文原始错误。

### 已知边界

- 英文界面不翻译上游返回原文、日志正文和诊断 JSON 字段名 —— 这些保留原文便于排障。
- 新增了「EN 字典不得有重复键」的用例：以后再往字典里加条目，重复会直接红灯。
- 面板仍没有 React error boundary；本版把所有已知的「字段缺失导致抛错」都改成了结构判空，但第三方插槽抛错还是会带走整页。

### 升级

tgz（推荐，可核对 SHA-256）：

```bash
dsh plugin --profile desktop add ./qoder-to-dsh-1.7.2.tgz
```

GitHub 直装：

```bash
dsh plugin --profile desktop add github:Ianzhyh/qoder-to-dsh
```

装完**完全退出 dsh 再打开**。如果面板顶部提示“已加载 vX，磁盘 vY”，说明还在跑旧代码。

- 凭据、偏好、用量、签到与目录缓存都在 `<DSH_HOME>/qoder`，升级不会清空。
- 已经登录的账号不需要重新授权。
- 资产 SHA-256：`9a40f2ff2ed8cb9e6ebc42726b6d5301ed3c75f73e59a54e2b9620893b64729b`（43 个文件，939.5 KB）。
