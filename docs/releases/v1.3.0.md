## 1.3.0

**这一版把上游错误与完成度做成可信语义。** 10605 模型排队会按 `retryAfter` 自动等待；110 日限、430 版本门、12153 会话失效不再盲目重试；只剩思考、没有正文或工具调用的回复会以 `EMPTY_RESPONSE` 结束，不再显示空白“成功”。

- **错误码分流**：10605 排队（含转义 JSON）、110 日限、112 额度、105/12153 会话、430 版本门、内容审核、114 试用受限分别归类；排队会带 `providerRetryAfterMs`，普通 401/403 仍保留一次刷新重试。
- **完成度校验**：reasoning-only 的 `stop`/`length` 报 `EMPTY_RESPONSE`；工具名为空/不合法、参数不是完整 JSON 时不写入会话，直接报 `INVALID_REQUEST`；兜底 tool id 每轮唯一。
- **额度真实性**：`remaining: 0` 会如实显示 0；额度缺失的诊断从 pass 改为 warn；首包默认超时提升到 90 秒。
- **体验修正**：版本漂移 banner；设置提示改为“下一次请求生效”；用量明细显示试跑/账号尾号/每日汇总标记；账号页说明插件当前账号与本机账号列表；签到结论按后端原文呈现。
- **验证**：184 个用例通过，`npm run release:check` 全绿。

### 升级

tgz（推荐，可核对 SHA-256）：

```bash
dsh plugin --profile desktop add ./qoder-to-dsh-1.3.0.tgz
```

GitHub 直装：

```bash
dsh plugin --profile desktop add github:Ianzhyh/qoder-to-dsh
```

装完**完全退出 dsh 再打开**（插件在宿主启动时加载；只重开面板不会换掉已加载的代码）。如果面板顶部提示“已加载 vX，磁盘 vY”，说明还在跑旧代码。
