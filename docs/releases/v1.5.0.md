## 1.5.0

**这一版补日常最常用的四件便利：多 PAT 保存/切换、缓存命中率、额度到期预警、对话页已用百分比。** 都是从同类 Qoder 插件 issue 里反复出现的使用反馈收敛来的，不改变单激活账号和纯插件的边界。

- **PAT 凭据库**：同一区域可保存多枚 `pt-` PAT，整文件用 DPAPI / AES-GCM 加密；账号页列出名称、区域、uid 尾号、添加/上次使用时间，可切换或删除。切换时重新走 `jobToken/exchange`，不保存短期访问令牌；面板和诊断包永不返回 PAT。
- **导入即保存**：`pt-` 导入成功后自动入库；`dt-` / `jt-` 仍只做一次性登录。当前正在使用的 PAT 不允许直接删除，需先切换或退出登录。
- **缓存命中率**：用量页 Tokens 卡显示 `cached_tokens / prompt_tokens`；请求明细新增「缓存」列（命中 tokens + 比例），CSV 增加 `cacheHitRate` 字段。缺失字段显示 `—`，不伪造 0%。
- **额度到期预警**：额度 7 天内到期显示 `X 天后到期`，已过期显示 `额度已过期`；额度卡与对话页胶囊同步。
- **对话页胶囊**：`剩余 / 总量` 后补已用百分比；临期或已过期时与低额度一样变黄。
- **诊断**：新增「PAT 凭据库」检查；若 `pats.json` 解密失败，会显示错误并保留原文件，不会静默清空。

### 边界

- **多 PAT 只收 `pt-`**：`dt-` / `jt-` 不保存；切换 PAT 需要网络换取短期令牌。
- **缓存命中率只反映前缀缓存**，不是计费折扣；系统提示词、工具顺序和会话历史变化都会影响它。
- **额度预警来自上游时间**：上游不返回到期时间时显示“不限期”，不要把它当成账单承诺。
- 仍不做自动切号、OpenAI/Anthropic 兼容端点、媒体/搜索桥、独立控制台或账号池化；中英双语留到 1.6。
