## 1.4.0

**这一版对齐 Qoder 0.5.1，并把账号、额度、请求与诊断补到可持续使用的成熟度。** 升级后的客户端版本、缓存与多账号状态会被如实识别；协议版本跟随客户端内置 CLI，可按环境变量回退。

- **Qoder 0.5.1**：COSY/UA 跟随 `umid/manifest.json` 的 `qoderCliVersion`（本次 1.1.79-hotfix.7），`QODER_COSY_VERSION` / `QODER_OAUTH_UA` 可覆盖，`QODER_PROTOCOL=legacy` 回退 1.1.75。
- **客户端环境**：解析 launcher `state.ini`、多版本目录、endpoint cache、`umid-cache.json`、`.qoder-app-status.json` 与 `location.v1.json` 数据目录搬迁；runtime-info 不可用时用设备缓存兜底。
- **账号**：别名、上移/下移、隐藏/恢复、恢复全部；同一账号的桌面/CLI 快照合并；切换落盘，官方客户端登录态不变。
- **额度**：多包归一化、同名不同到期分组、不限量 `∞`、账号不一致与 404/405 旧构建提示；额度卡不再自己拼两个桶。
- **请求**：新增请求明细页，支持模型筛选、仅失败、暂停、复制单条与 CSV（BOM + 公式注入防护）；用量页新增按账号聚合与每日 CSV。
- **日志/诊断**：独立日志页；新增 6 项客户端/协议/缓存/端点检查；诊断包会截断邮箱与 uid 并脱敏令牌；客户端升级后提示 401 重登，目录缓存按 CLI 版本后台刷新。
- **无障碍**：9 个页签补齐 tablist/tab/tabpanel 与 `aria-controls`/`aria-labelledby`，窄屏横滑。
- **验证**：237 个离线用例通过；`npm run test:live` 在 Qoder 0.5.1 返回 `pong`；离线 CDP 渲染 9 页签、账号别名/隐藏、请求表、日志页、升级黄条与暗色主题，console errors 0。

### 升级

tgz（推荐，可核对 SHA-256）：

```bash
dsh plugin --profile desktop add ./qoder-to-dsh-1.4.0.tgz
```

GitHub 直装：

```bash
dsh plugin --profile desktop add github:Ianzhyh/qoder-to-dsh
```

装完**完全退出 dsh 再打开**（插件在宿主启动时加载；只重开面板不会换掉已加载的代码）。如果面板顶部提示“已加载 vX，磁盘 vY”，说明还在跑旧代码。

- 如果刚升级过 Qoder 客户端，面板会出现“客户端已升级”黄条；如遇 401，请先在官方客户端重新登录，再完全重启 dsh。
- 协议回退：`QODER_PROTOCOL=legacy`（或在环境里设置 `QODER_COSY_VERSION=1.1.75`）。
- 资产 SHA-256：`2532f995ab1bc1df760e0d863ccba31cddb51e42415555679cd94ef685c84d23`（37 个文件，635.4 KB）
- 完整变更见 [CHANGELOG](https://github.com/Ianzhyh/qoder-to-dsh/blob/v1.4.0/CHANGELOG.md)。

### 边界

- **不做**：自动切号、OpenAI/Anthropic 兼容端点、Codex/Claude Code/opencode 接入、媒体/搜索桥、独立控制台、账号池化。
- **双语留到 1.5**：面板当前仍为中文；完整英文需要逐条词条与动态规则，本版不仓促上线。
- 账号排序用上移/下移按钮，未做拖拽。

### 验证

- `npm run release:check`：模块语法 + 237 个用例 + 安装自检（`--offline`）
- `npm run verify:release`：产物与工作区逐字节一致、exports 目标齐全、locale 键一致、README / CHANGELOG / 双份版本号一致
- 新增回归：安装根/manifest/协议/端点白名单/location/symlink/umid-cache、额度分组与不限量、账号别名/排序/隐藏/合并、请求筛选、CSV 注入、诊断包脱敏、a11y 页签配对

> 非官方互操作实现，只使用你自己合法授权的 Qoder 账号；上游协议可能随时变化。失效时先看设置里的「诊断」页。
