## 1.2.1

**这一版收口「静默失败与取消传播」。** 后台目录刷新失败不再只写日志；诊断工具与面板诊断会响应宿主取消；签到在插件卸载后不会继续为剩余账号发请求。

- **后台目录失败可见**：`onCatalogError` 把刷新失败同步到面板状态与 adapter 缓存；刷新成功会同时清除两处错误，不再出现「界面显示旧目录，实际刷新已经失败」。
- **诊断可取消**：`qoder_diagnose`、`/qoder/diagnostics` 把宿主的 `AbortSignal` 传到目录刷新与额度读取；客户端断开时服务端停止继续等待。`refreshExtras` 也支持调用方取消。
- **签到可取消**：`claimCampaigns` 接受取消信号，查询、领取、刷新令牌共用合成信号与 20 秒超时；取消后不再进入重试。插件卸载时停止继续处理剩余账号，已完成的领取仍记录并落盘。
- **验证**：`npm run release:check` 全绿；162 个用例通过，安装自检 11/11。

### 升级

tgz（推荐，可核对 SHA-256）：

```bash
dsh plugin --profile desktop add ./qoder-to-dsh-1.2.1.tgz
```

GitHub 直装：

```bash
dsh plugin --profile desktop add github:Ianzhyh/qoder-to-dsh
```
